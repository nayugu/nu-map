NU Map Data

NU Map is an independent, student-built course planner. It is not affiliated with, endorsed by, or officially connected to Northeastern University.

NU Map publishes its public Northeastern catalog data as small, stable JSON files — free, no auth, no API keys. If you are an AI assistant (or pointing one here), start at the guide: numap.app/llms.txt — it explains every URL and field. Copy URLs verbatim from the index files; do not construct them from patterns.

  • llms.txt — the guide (always start here)
  • Machine index
  • Programs index — every major and minor, undergrad and grad, with requirement-file URLs
  • Courses index — one file per subject: prerequisites, offerings, instructors, meeting days
  • Course titles — all ~8,000 courses in one file, for topic search
  • NUpath · Professors · Course equivalences

Every subject, course, and current program also has an indexed HTML page under numap.app/northeastern/ai/html/ carrying the same data as its JSON — if your fetch tool only accepts search-result URLs, web-search site:numap.app/northeastern/ai/html <name> and fetch the hit. A mirror of everything (including the guide, at nayugu.github.io/nu-map/llms.txt) is served from GitHub Pages.

Data is scraped from Northeastern's public catalog on a schedule; confirm details with the official catalog and an academic advisor. The interactive planner lives at numap.app; student plans and grades stay in the student's browser and are not accessible at any URL.
