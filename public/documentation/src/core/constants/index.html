constants.js + themes.js Compile-time

Compile-time constants shared across all layers. No functions, no logic — just exported values. constants.js exports four constants. themes.js defines CSS variable token sets for each UI theme.

Parent
core/
Imported by
courseModel.js, semGrid.js, gradRequirements.js, PlannerContext.jsx, Header.jsx, ThemeContext.jsx

constants.js exports

ExportTypeUsed byPurpose
NUM_YEARSnumber (5)semGridDefault number of academic years to generate in the full semester grid
SUBJECT_PALETTEstring[25]courseModel25 dark-theme CSS hex colors for the deterministic subject color hash
TYPE_BGobjectSemRow, SummerRowMaps semester type ("fall", "spring", "summer", "special") to CSS variable name pairs { bg, border } used for row backgrounds
REL_STYLEobjectRelationLines, InfoPanel legendSVG line styles { color, dash, label, arrow } keyed by relationship type

NUPath labels, co-op/internship templates, and semester type lists are not in this file — they live in the northeastern adapter (attributeSystem.js, specialTerms.js) so they stay institution-specific.

REL_STYLE — relationship line styles

export const REL_STYLE = {
  prerequisite:                  { color: '#3dd8a0', dash: '',     label: 'Prereq',                           arrow: true  },
  'prerequisite-order':          { color: '#f85149', dash: '',     label: 'Prereq (wrong order)',               arrow: true  },
  corequisite:                   { color: '#58a6ff', dash: '5 4',  label: 'Coreq',                             arrow: false },
  'corequisite-viol':            { color: '#ffd600', dash: '5 4',  label: 'Misplaced',                         arrow: false },
  'substitution-prereq':         { color: '#3dd8a0', dash: '4 3',  label: 'Substituted prereq',                 arrow: true  },
  'substitution-prereq-order':   { color: '#f85149', dash: '4 3',  label: 'Substituted prereq (wrong order)',  arrow: true  },
};

Prerequisites use mint green (#3dd8a0) when satisfied and red (#f85149) when ordered wrong. Corequisites use blue (#58a6ff) dashed. Substituted-course variants mirror the same colors with a shorter dash. There is no "substitution" key — substitution relationships are represented as either "substitution-prereq" or "substitution-prereq-order".

themes.js exports

Each theme is a plain object mapping CSS variable names to values. ThemeContext injects these onto document.documentElement at runtime.

ExportTypePurpose
darkobject (~100 CSS vars)Default dark theme token set
lightobject (~100 CSS vars)Light theme token set
THEMES{ dark, light, ... }All available themes — ThemeContext iterates keys
THEME_LABELS{ dark: "Dark", ... }Human-readable theme names for the UI

Key CSS variable groups

// Backgrounds
--bg-app, --bg-surface, --bg-surface-2, --bg-card

// Text hierarchy (1 = most prominent)
--text-1, --text-2, --text-3, --text-4, --text-5, --text-6

// Borders
--border-1, --border-2, --border-3

// Semester type colors
--sel-fall-bg, --sel-fall-border, --sel-fall-text
--sel-spr-bg,  --sel-spr-border,  --sel-spr-text

// Status colors
--active, --success, --error, --warn, --warn-bright

// Scrollbar
--scrollbar-thumb, --scrollbar-track
💡
Adding a theme: Copy the dark object, adjust values, export it, add to THEMES and THEME_LABELS. ThemeContext and Header will pick it up automatically with no other changes needed.
