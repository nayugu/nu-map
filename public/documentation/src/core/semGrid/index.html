semGrid.js Core logic

Generates the ordered list of semesters for a student's cohort window and computes fast lookup maps. Called whenever entry or graduation dates change. Semester layout is driven by the ICalendar adapter when provided; falls back to the legacy NU-compatible hardcoded layout when omitted.

Semester ID format

Semester IDs are human-readable stable strings, used as keys across the whole app. The spring prefix is "spr" (not "spring") — this is set by the NU calendar adapter's idPrefix for backward-compatibility with saved plans.

"incoming"    → Pre-matriculation (transfer credit / AP / IB / waiver)
"fall2026"    → Fall 2026
"spr2027"     → Spring 2027
"sumA2027"    → Summer 1 2027
"sumB2027"    → Summer 2 2027

Exported functions

generateSemesters(startYear, numYears?, calendar?) → Semester[]
Generates the full ordered semester list starting from startYear. Always prepends the "incoming" slot at index 0. When calendar is provided, uses calendar.getSemesterTypes() to determine which semester types to generate and in what order. Without calendar, falls back to the legacy NU layout (fall, spring, sumA, sumB per year).
Parameters: startYear = first academic year; numYears = defaults to NUM_YEARS (5); calendar = optional ICalendar adapter
buildCohortSemesters(planEntSem, planEntYear, planGradSem, planGradYear, calendar?) → Semester[]
Builds the trimmed semester list for a cohort window (entry → graduation + 1 buffer year). Always keeps "incoming" at index 0. Calls generateSemesters() internally, then slices to the entry–graduation range. The calendar parameter is forwarded to generateSemesters(); without it, falls back to the legacy NU layout.
Returns: Semester[] starting with "incoming", then entry semester through graduation semester
Parameters: planEntSem/planGradSem = semester type ID ("fall", "spring"); planEntYear/planGradYear = calendar years; calendar = optional ICalendar adapter
deriveSemMaps(semesters) → { SEM_INDEX, SEM_NEXT, SEM_PREV }
Computes three O(1) lookup maps from the semester array. All are plain objects:
  • SEM_INDEX: { semId → ordinal } — used to compare "is A before B?" (prereqEval, planModel)
  • SEM_NEXT: { semId → nextSemId } — used to advance one semester
  • SEM_PREV: { semId → prevSemId } — used to go back one semester
Returns: { SEM_INDEX, SEM_NEXT, SEM_PREV }

The incoming semester

Every cohort grid starts with the fixed "incoming" slot at ordinal 0. It represents transfer credits, AP/IB exam credit, and course waivers — courses placed here satisfy prerequisites for any semester that follows. maxSlots: 99 means no overflow warning is ever shown.

{ id: "incoming", label: "Incoming Credit", sub: "Transfer / AP / IB / Waiver",
  type: "special", semTypeId: "incoming", maxSlots: 99 }
