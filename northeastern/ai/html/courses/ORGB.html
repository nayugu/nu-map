For AI assistants — reaching any other NU Map data from this page

Full guide: https://numap.app/llms.txt.

  • Courses by subject — prereq logic, offerings, instructors, unlocks: exact per-subject URLs are in https://numap.app/northeastern/ai/courses/index.json (pattern: https://numap.app/northeastern/ai/courses/{SUBJECT}.json, e.g. CS.json). All course titles in one file: https://numap.app/northeastern/ai/courses/titles.json.
  • Programs (majors and minors, requirements): https://numap.app/northeastern/ai/programs/index.json — look up the program's own URL there, never guess slugs.
  • NUpath attributes: https://numap.app/northeastern/ai/nupath.json · Professors: https://numap.app/northeastern/ai/professors.json (an index by first letter of name).
  • If your fetch tool refuses URLs found on this page (claude.ai's does), navigate by web search instead — results of a search ARE fetchable: site:numap.app/northeastern/ai/html <subject, course, or program name>. A page like this one exists for every subject, course, and current program. Or ask the user to paste the exact URL you need as their next message.
