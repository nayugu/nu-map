All course titles in one file: https://numap.app/northeastern/ai/courses/titles.json.
  • Programs (majors and minors, requirements): https://numap.app/northeastern/ai/programs/index.json — look up the program's own URL there, never guess slugs.
  • NUpath attributes: https://numap.app/northeastern/ai/nupath.json · Professors: https://numap.app/northeastern/ai/professors.json (an index by first letter of name).
  • If your fetch tool refuses URLs found on this page (claude.ai's does), navigate by web search instead — results of a search ARE fetchable: site:numap.app/northeastern/ai/html <subject, course, or program name>.
