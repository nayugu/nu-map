# Course Data Update Guide

## Overview

Course data (`public/northeastern/catalog-courses.json`, the runtime file) is scraped monthly from catalog.northeastern.edu and Banner by the `update-courses.yml` workflow. `all-courses.json` is the scrape intermediate — originally seeded from the [ninest/nu-courses](https://github.com/ninest/nu-courses) API, now maintained by our own scrapers.

Majors and minors are scraped from catalog.northeastern.edu by `scripts/scrape-majors.js` into `data/northeastern/programs/majors/`.

---

## Legacy: full resync from ninest/nu-courses (manual only)

Superseded by the monthly `update-courses.yml` scrape — course data now refreshes automatically. Kept only as a manual fallback for rebuilding the `all-courses.json` baseline from scratch; note it overwrites the baseline with ninest API data, so review the diff carefully:

```bash
# 1. Fetch fresh snapshot — review the diff before writing
node scripts/fetch-courses.js

# 2. If the diff looks right, write it
node scripts/fetch-courses.js --write

# 3. Re-apply local patches on top
node scripts/apply-patches.js --write

# 4. Build and verify
npm run build
```

Open a PR with the updated `public/all-courses.json`. GitHub Actions will automatically post a diff summary as a PR comment.

---

## Manual Corrections (incremental patches)

When a specific course is wrong, missing, or needs early removal:

1. Copy `data/northeastern/patches/TEMPLATE.yaml` to a new file: `data/northeastern/patches/YYYY-MM-DD_short-description.yaml`
2. Fill in only the sections you need (`add`, `update`, or `remove`).
3. Run validation locally:
   ```bash
   node scripts/validate-patches.js
   ```
4. Preview changes:
   ```bash
   node scripts/apply-patches.js
   ```
5. Open a PR. GitHub Actions will validate and post a diff summary.

## Updating Majors / Minors

Major and minor requirement files live in `data/northeastern/programs/majors/{year}/{college}/{slug}/parsed.initial.json` (minor folders end in `_minor`).

These files are regenerated by the scheduled `update-majors` / `update-grad-majors` workflows, so **do not hand-edit them** — the next scrape overwrites manual changes. If a program's data is wrong, fix the extraction in `scripts/scrape-majors.js` (or the grad equivalent) and re-run it.

## npm Scripts

| Command | What it does |
|---------|-------------|
| `npm run data:fetch` | Dry-run fetch — shows diff, no write |
| `npm run data:fetch:write` | Fetch and overwrite `all-courses.json` |
| `npm run data:patch` | Dry-run apply patches — shows changes |
| `npm run data:patch:write` | Apply patches and overwrite |
| `npm run data:validate` | Validate all patch files (used by CI) |
| `npm run data:update` | Full update: fetch + catalog scrape/merge + patches + nuPath merge (all --write) |

## Patch File Format

See `TEMPLATE.yaml` for a fully annotated example.

### Required fields for `add`:
- `subject` — 2–6 uppercase letters (e.g. `CS`)
- `number` — 4-digit string (e.g. `"2500"`)
- `title` — course title
- `credits` — positive number

### NUPath codes
`ND` `EI` `IC` `FQ` `SI` `AD` `DD` `ER` `CE` `WI` `EX`

### scheduleType values
`Lecture` `Lab` `Seminar` `Studio` `Individual Instruction` `Off-campus instruction`
